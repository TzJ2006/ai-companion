▼ test_ast_computeFunctionIdentity.test.ts 34 tests @aidev/ast (identity)
Strategy
Property-based: verify hash stability, uniqueness, and the contract (same inputs → same hash; different inputs → different hash).
Mock Approach
No mocks — computeFunctionIdentity is pure (crypto.createHash). Test against real SHA-256.
Coverage Target
computeFunctionIdentity — all hash dimensions
Test Categories
Structural correctness 4 Return type has hash, file_path, function_name, class_name, param_signature
Hash stability 5 Same inputs always produce same 16-char hex hash
Sensitivity to file_path 3 Same function in different files → different hash
Sensitivity to class_name 4 Method vs standalone function → different hash
Sensitivity to params 8 Adding/changing param types changes the hash
Insensitivity to line numbers 4 Moving function (same content) keeps same hash
Insensitivity to body 3 Changing function body doesn't change identity hash
Edge cases 3 Empty params, unicode names, very long paths
