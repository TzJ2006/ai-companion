# The idea graph — format（本文件已冻结，正本是 companion/FORMAT.md）

**这份文件已经冻结，它不再是规范。** 唯一权威的规范是 `companion/FORMAT.md` ——
节点长什么样、八个问题、边、生成出来的那些文件，以及三套实现之间每一处分歧的
裁决，全都在那一份里。读到这里的人和 agent 请立刻改读它，本文件不再描述任何格式。

**它在哪：和本文件同一个 ai-companion 检出里，`claude-companion/` 的隔壁目录。**
如果你是在别的仓库里读到这行的，那个仓库里没有这份规范 —— 装机时引擎并没有被
复制过去，五个命令文件指的是 ai-companion 检出里的这一份共享副本。跑一句
`npx tsx claude-companion/ideas.ts paths` 就能看见那个检出的绝对路径，规范就在
它下面的 `companion/FORMAT.md`。

不删掉它，是因为已经装进别的仓库的那五个命令文件按这个名字指着它 ——
删了它们只会拿到一个「文件不存在」。它现在只做一件事：把人送到正本去。

## 曾经写在这里、并且和正本相反的三条

三条一律以正本为准。列在这里，是为了让照着旧版本做过事的人知道自己错在哪一条：

| 这里以前怎么说 | 正本怎么裁 |
|---|---|
| 人工验证由人自己把名字和日期写进 `signed_off` | **D27** —— 签字只能由一次性的人工验收 challenge 产生，再由命令行写回图；直接编辑已经有值的 `signed_off` 会被拒。一个 agent 能编辑的签名，证明不了人看过结果。 |
| 自动验证只写 `command`，测试文件靠从命令字符串里猜 | **D2** —— `verify` 额外写一份显式的 `test_files` 列表；含空格的路径、参数和通配符都会猜错，所以绝不从命令里猜。 |
| 裸名 `ideas/graph.yaml` 被占就加 agent 后缀，每个 agent 一份图 | **D10** —— 一个项目只有一份 `ideas/graph.yaml`，不带 `agent:` 键，三个 agent 共用图、日志、批准和证据；旧的后缀图只读，只能由显式的 `migrate` 迁过去。 |

旧版本留在 git 历史里。这里不再保留任何一条格式规则。
